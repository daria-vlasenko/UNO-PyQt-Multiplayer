# UNO PyQt Multiplayer

UNO — классическая карточная игра, реализованная на Python с графическим интерфейсом **PyQt5** и сетевым взаимодействием по **TCP/UDP**.

Игра поддерживает как локальные **LAN-матчи**, так и однопользовательский режим вдвоём на одном устройстве.

## ✨ Возможности

* Создание и поиск игры по коду с использованием UDP-броадкаста
* TCP-соединение для передачи игровых команд
* Анимация раздачи и выкладывания карт на стол
* Все стандартные карты UNO:

  * Цифры 0–9 для четырёх цветов
  * **Skip** — пропуск хода
  * **Reverse** — смена направления
  * **Draw Two (+2)** — взять две карты
  * **Wild** — смена цвета
  * **Wild Draw Four (+4)** — смена цвета и взять четыре карты
* Выбор цвета при сыгрывании **Wild** и **+4**
* Блокировка интерфейса, если сейчас ход другого игрока
* Встроенное окно с правилами игры в формате HTML
* Упаковка приложения в `.exe` с помощью **PyInstaller**

│   ├── server.py              # Серверная часть, приём/раздача ходов

├── GUI/                       # Окна PyQt5
│   ├── main_window.py         # Главное меню
│   ├── create_game_window.py  # Окно создания/запуска сервера
│   ├── join_game_window.py    # Окно подключения к серверу
│   ├── game_window.py         # Игровое поле, анимации, ввод ходов

## ⚙️ Установка зависимостей

Требуется **Python 3.8+**.

Клонируйте репозиторий:

```bash
git clone https://github.com/ArtemIvanovski/UNO.git
cd uno-pyqt
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

### `requirements.txt`

```text
PyQt5>=5.15
```

## 🚀 Запуск из исходников

После установки зависимостей запустите приложение:

```bash
python app.py
```

В главном меню выберите:

* **Создать игру** — для создания игры и запуска сервера
* **Присоединиться к игре** — для подключения к существующей игре

## 🖥 Упаковка в `.exe`

Для создания исполняемого файла используется `auto-py-to-exe`.

Установите инструмент:

```bash
pip install auto-py-to-exe
```

Запустите GUI-конфигуратор:

```bash
auto-py-to-exe
```

### Настройки сборки

Укажите следующие параметры:

| Параметр         | Значение                    |
| ---------------- | --------------------------- |
| Script Location  | `app.py`                    |
| Output           | `One Directory`             |
| Console Window   | Включить, чтобы видеть логи |
| Icon             | `assets/icon.ico`           |
| Additional Files | `assets;assets`             |

После настройки нажмите **Convert .py to .exe**.

Результат сборки появится в папке:

```text
output/
```

## 📖 Правила UNO

В меню **Правила** приложения открывается встроенный HTML-файл:

```text
assets/rules.html
```

В нём подробно описаны:

* Состав колоды — 108 карт
* Все карты-действия и их эффекты
* Порядок раздачи карт и выполнения ходов
* Система очков
* Условия завершения раунда
